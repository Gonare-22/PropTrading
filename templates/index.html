EMA 20/50/100 Strategy Backtest

Dynamic backend-driven backtest for Indian, US, and Forex markets.

How the strategy works

Bullish signal: 50 EMA crosses above 100 EMA. This means the medium-term trend is turning up, so the system enters a long trade.

Bearish signal: 50 EMA crosses below 100 EMA. This means the medium-term trend is turning down, so the system enters a short trade.

Exit signal: 20 EMA crosses the 50 EMA. That means the short-term price momentum is reversing, so the strategy exits the current position.

Trade sizing: The system uses the full available equity to calculate entry units, i.e. entry_units = equity / entry_price. This is a notional position size, and the engine assumes the entire capital is used per trade.

Note: Actual broker margin and risk sizing are not simulated. The model uses the reported initial capital only for signal sizing and P&L calculation.
